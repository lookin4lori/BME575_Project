### 2b. Classifier head — Kaiyao Hou

I added `scripts/classifier.py` on top of the team's DenseNet121 feature-extraction backbone. Its head applies global average pooling to the backbone feature map, optional configurable dropout (default 0.5), and one sigmoid output. The output is the estimated probability of **any diabetic retinopathy**: 0 means no DR (diagnosis grade 0), and 1 means any DR (grades 1–4). This matches the scalar binary labels produced by `scripts/dataset.py`. The model expects that pipeline's already preprocessed 224 × 224 RGB tensors, so the head does not preprocess images a second time. (*HandoverNotes.pdf*, p. 5; *ML_ProgressReport1.pdf*, pp. 6, 8.)

The classifier compiles with Adam and binary cross-entropy. `build_classifier` starts with a frozen DenseNet121 backbone by default. `set_classifier_backbone_trainable` can freeze it again or unfreeze a specified number of its final dense blocks; batch-normalization layers remain frozen under the repository's default setting. After a trainability change, it recompiles the model with a fresh optimizer so the new trainable weights are included in training. This implements the frozen-feature baseline and provides an explicit path for later fine-tuning; it does not prescribe when to fine-tune. (*ML_ProgressReport1.pdf*, pp. 6, 8.)

The reference paper describes DenseNet121 with global average pooling and a fully connected classifier, and reports TensorFlow/Adam binary classification. Its Table 4 lists a batch size of **32**, **50** epochs, initial learning rate **0.01**, and minimum learning rate **0.00005** for DenseNet. Those values are retained in `config.py`. The paper uses generic softmax language for its output and does not specify a dropout rate, an exact binary loss, the ImageNet weight source, or a layer-unfreezing schedule. For the team's one-dimensional binary labels, the **single sigmoid output, binary cross-entropy, and 0.5 dropout default are implementation choices**, consistent with the progress report's pipeline diagram rather than exact hyperparameters taken from the paper. (Mohanty et al., *Sensors* 2023, 23, 5726, §§4.3–4.4 and Table 4; *ML_ProgressReport1.pdf*, p. 8.)

This section supplies architecture and compilation functions only. The configured 50 epochs and minimum learning rate are reference settings, not a training schedule implemented here. No model accuracy, sensitivity, or other performance result is claimed.
